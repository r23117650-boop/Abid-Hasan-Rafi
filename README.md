## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Select deployment from the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.
6. Edit the canonical URL and `og:url` in `index.html` to your actual GitHub Pages URL or custom domain.
7. Replace the LinkedIn placeholder URL with your real LinkedIn profile.

## SEO notes
- A website cannot guarantee first place or immediate appearance in Google.
- After publishing, add the site to Google Search Console and submit the sitemap when you add one.
- For a custom domain, create a `sitemap.xml` and `robots.txt`, then submit the sitemap in Search Console.
- Keep your name and professional details consistent across profiles. Add only genuine experience, case studies, credentials, and results.
- Google indexing can take time. Search Console helps monitor indexing and search queries.
